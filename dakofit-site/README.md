# Dako Fit Website

Static site for dako.life — personal training, body repair, movement restoration, and martial arts in Brockton, MA.

## Files
- `index.html` — the full site (self-contained, all CSS/JS inline)
- `video1.mp4` – `video4.mp4` — service demonstration clips, referenced directly by `index.html`

## Deploy
Connected to Netlify via GitHub integration — any push to `main` triggers an automatic redeploy.
